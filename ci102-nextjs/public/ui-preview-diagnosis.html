🧮 指標の計算フロー（CI102） — LQ → 基盤雇用 → EBM → PER → 人口・世帯・住宅需要（福岡県・中分類）
1① 特化係数 LQ（何で稼ぐ地域か）

LQ = (地域の産業別従業者比) ÷ (全国の産業別従業者比)

例: 医療業 LQ 1.30 / 社会保険・社会福祉・介護事業 LQ 1.13 / その他の事業サービス業 LQ 1.13

LQ>1 = 全国平均より特化 = 域外に売って所得を稼ぐ『基盤』産業。

2② 基盤雇用 Basic Employment

基盤雇用 = Σ 各産業の超過雇用（LQ>1分）= local_emp × (1 − 1/LQ)

基盤雇用 188,879 人 ／ 総雇用 2,435,977 人（基盤比率 8.2%）

域外需要に支えられた雇用。地域経済のエンジン。

3③ 経済基盤乗数 EBM

EBM = 総雇用 ÷ 基盤雇用

EBM = 2,435,977 ÷ 188,879 = 12.23

基盤雇用1人が地域全体で約12.2人の雇用を生む波及力。高め=基盤過小/通勤流入の可能性。

4④ 人口・雇用比 PER

PER = 人口 ÷ 総雇用

PER = 5,081,879 ÷ 2,435,977 = 2.09

雇用1人あたりの人口。雇用増が人口(需要)へ波及する係数。

5⑤ 予測カスケード（乗数の効き方）

Δ基盤雇用 →(×EBM) Δ総雇用 →(×PER) Δ人口 →(÷世帯人員) Δ住宅戸数

基盤+1,000人 → 総雇用 +12,230 → 人口 +25,514 → 住宅 +12,035 戸

新規の基盤雇用(工場誘致・本社移転等)が住宅需要へ波及する理論量。投資インパクトの試算に。

※ 乗数(EBM/PER)は現在の産業構造が続くと仮定した理論値。基盤雇用はLQ>1産業の超過雇用の合計。

基盤雇用 = Σ 各産業の超過雇用（LQ>1分）= local_emp × (1 − 1/LQ)

基盤雇用 2,289,789 人 ／ 総雇用 9,930,865 人（基盤比率 23.9%）

域外需要に支えられた雇用。地域経済のエンジン。

3③ 経済基盤乗数 EBM

EBM = 総雇用 ÷ 基盤雇用

EBM = 9,930,865 ÷ 2,289,789 = 4.19

基盤雇用1人が地域全体で約4.2人の雇用を生む波及力。CI102健全域(3〜6)。

4④ 人口・雇用比 PER

PER = 人口 ÷ 総雇用

PER = 14,246,219 ÷ 9,930,865 = 1.43

雇用1人あたりの人口。雇用増が人口(需要)へ波及する係数。

5⑤ 予測カスケード（乗数の効き方）

Δ基盤雇用 →(×EBM) Δ総雇用 →(×PER) Δ人口 →(÷世帯人員) Δ住宅戸数

基盤+1,000人 → 総雇用 +4,190 → 人口 +6,011 → 住宅 +3,197 戸

新規の基盤雇用(工場誘致・本社移転等)が住宅需要へ波及する理論量。投資インパクトの試算に。

※ 乗数(EBM/PER)は現在の産業構造が続くと仮定した理論値。基盤雇用はLQ>1産業の超過雇用の合計。
