### ✅ Step 4: NLNI×経済 4軸クロス散布図 (/compare)

### ✅ Step 19: Decision Hub の AI 自然言語化
- `/api/ai-decision` — Claude API 統合

- EBM の正しい解釈・What-If と実績の区別・通勤歪み注釈を含む
- 500-800 字の Markdown 形式

### ✅ Step 17: 立地適正化「居住誘導 vs 都市機能誘導」区別
- precompute_json で各市区町村の区域種別を判定
- `has_residential_zone` (居住誘導 or 居住調整)
- `has_function_zone` (都市機能誘導)
- DecisionHub の住居系/商業系スコアに反映
  - 居住誘導区域あり → 住居系 100点
  - 都市機能誘導区域あり → 商業系 100点
