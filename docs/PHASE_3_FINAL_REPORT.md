### ✅ Step 21: 商圏分析の OSRM 走行時間ベース化
営業現場で「商圏」を語る際の最大の不正確要因が、直線距離(haversine)による分断地形の無視。
OSRM Table API プロキシを実装し、車での実到達範囲をリアルタイム計算可能に。

- 新エンドポイント `POST /api/osrm-table` (OSRM 公開デモサーバへのプロキシ)
- `findMunicipalitiesInDriveTime()`: haversine事前フィルタ → OSRM Table バッチ呼出
- バッチ分割 (80件/req, 200ms間隔), 上限500宛先, 日本範囲検証
- UI: 📏直線距離 (km) ⇔ 🚗走行時間 (分) のモード切替
- 走行時間オプション: 10/15/30/60/90分
- 例: 神戸→淡路島 直線3km だが実走30分 → 正しく除外される
