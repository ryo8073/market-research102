# 不動産市場分析ダッシュボード v2 — UI/UX 仕様書

## ビジョン

> 「この分析がなかったら、あの投資判断は成功しなかった」

不動産投資家・機関投資家が**5分で地域の投資適格性を判断**できるダッシュボード。
CCIM CI102の分析フレームワークを、日本の公的統計データで自動実行し、
STDB/Esri Business Analyst/CoStar級の品質で可視化する。

---

## 設計原則

| 原則 | 説明 |
|------|------|
| **投資判断ファースト** | 学術的説明ではなく「で、投資すべきか？」に答える |
| **マクロ→ミクロ** | 全国→都道府県→市区町村→物件レベルへ自然にドリルダウン |
| **1画面1判断** | 各タブは1つの投資判断材料を提供する |
| **色は意味を持つ** | 青系パレット基調。赤緑は使わない（色覚多様性対応） |
| **数字は文脈で語る** | 単独の数値ではなく、全国平均・経年変化との比較で表示 |

|------|------|-----------------|

- EBMとPERは「経済基盤」タブに統合（別タブにする必要なし）

各カードに以下を含める（CoStar/Moody's パターン）:
- **メイン値**: 大きなフォント
- **全国順位**: 「47都道府県中 第X位」

- **全国平均との差**: 「全国平均 +12%」等


### 投資シグナル

LQとシフトシェアの結果を**投資家が即座に読める形**に変換:

| シグナル | 条件 | アイコン | 意味 |
|---------|------|---------|------|
| 基盤産業 | LQ > 1.0 | ● ティール | 域外からお金を呼ぶ産業 |
| 競争優位 | RS > 0 かつ 実雇用増 | ● ティール | 全国を上回る成長力 |
| 注意 | LQ > 1.0 だが RS < 0 | ● アンバー | 基盤だが競争力は低下中 |
| リスク | RS < 0 かつ 実雇用減 | ● コーラル | 衰退トレンド |

### expanderの書き換え（教科書スタイル → 実務スタイル）

**Before（現行）**:
> この指標の意味（CI102 Module 4: Demand Analysis）
> LQ = 地域の産業iの従業者数 / ... [数式]

**After**:
> **投資判断への活用**
>
> 特化係数（LQ）が1.0を超える産業は、この地域から域外へ財やサービスを
> 「輸出」し、外部資金を流入させています。この外部資金の流入こそが
> テナント需要を生み、不動産価値を支える根源的な力です。
>
> **着目ポイント**:
> - LQ > 1.5 の産業が複数ある → 経済基盤が多様化しており安定
> - LQ > 2.0 の産業が1つだけ → 一極集中リスク（ピッツバーグの鉄鋼業と同じ構造）
> - シフトシェアのRS（競争要因）が正 → 同じ産業の全国平均を上回る成長力

## expander テキスト一括書き換え

すべてのexpanderラベルを「投資判断への活用」に統一し、
教科書的な数式説明を投資家目線の実務ガイドに書き換える。

### Tab① 経済基盤

**ラベル**: 「投資判断への活用」

**本文**:
```
特化係数（LQ）が1.0を超える産業は、この地域から域外へ
財やサービスを「輸出」し、外部資金を流入させる基盤産業です。

■ 着目ポイント
・LQ > 1.5 の産業が複数 → 基盤が多様化しており投資リスクが低い
・LQ > 2.0 の産業が1つだけ → 一極集中リスクに注意
・経済基盤乗数(EBM)が大きい → 基盤雇用1人の増減が地域全体に大きく波及

■ シフトシェアとの組合せ
・LQ > 1.0 かつ RS > 0 → 競争力のある基盤産業（最優良シグナル）
・LQ > 1.0 かつ RS < 0 → 基盤だが競争力低下中（要警戒）
```

### Tab③ 小売市場

**ラベル**: 「投資判断への活用」

**本文**:
```
漏損（Leakage）は、地域住民の購買力が域外に流出している状態です。
漏損が大きいセクターは、新規出店により購買力を地域内に取り戻せる
可能性があり、商業不動産の投資機会を示唆します。

■ 漏損セクターの読み方
・漏損係数 +10以上 → 出店機会あり（需要 > 供給）
・漏損係数 -10以下 → 供給過多（追加出店はカニバリゼーションのリスク）
・需要の推計は、地域人口 × 全国平均の1人あたり小売支出額で按分しています。

■ 注意
・食料品・日用品は職場近くで購入する傾向が強く、
  居住地ベースの漏損率が実態より高く出る場合があります。
```

### Tab④ 不動産取引

**ラベル**: 「投資判断への活用」

**本文**:
```
経済基盤分析（Tab①）で特定した基盤産業の強さが、
実際の不動産価格にどう反映されているかを確認します。

■ 着目ポイント
・基盤産業が強い地域 → 取引価格が安定・上昇傾向か？
・シフトシェアでRS(競争要因)が正の産業が集積するエリア → ㎡単価は上がっているか？
・物件タイプ別の㎡単価分布 → 割安なセグメントはどこか？
```
