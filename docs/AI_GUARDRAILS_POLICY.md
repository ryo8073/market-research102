# AI 投資判断レポート ガードレール方針

## 背景

LLM (Claude API) を用いた投資判断レポート生成には、不動産業界・金融分野
特有の法的・倫理的リスクがある。本ドキュメントは Phase 3 で実装した
`/api/ai-decision` の信頼性を確保するためのベストプラクティスを定義する。

## 関連法規・ガイドライン

| 法規 | 適用範囲 | 本ツールへの影響 |
|---|---|---|
| 金融商品取引法 | 金融商品（証券・FX等）の助言 | 不動産は対象外だが思想は参考 |
| 宅地建物取引業法 | 不動産取引の重要事項説明 | 「断定的判断の提供」禁止 |
| 消費者契約法 | 重要事項の不実告知 | 誤認を招く表現は不可 |
| 景品表示法 | 優良誤認・有利誤認表示 | 過度な投資推奨は不可 |
| 個人情報保護法 | 個人データの第三者提供 | 住所など PII を API 送信時注意 |
| EU AI Act (参考) | 高リスクAI システム | 透明性・人間監督・記録保持 |
| Anthropic Usage Policy | Claude API 利用 | 高リスク判断の AI 独占禁止 |

## 4層ガードレール

### Layer 1: 入力 (Input Guardrails)

#### 1.1 データのサニタイズ
- 送信データから明らかな PII（個人住所・氏名・連絡先）を除去
- 数値範囲の検証（負の人口、1000%超のEBM等）
- 必須フィールドの存在確認

#### 1.2 プロンプトインジェクション対策
- ユーザー入力を `userMessage` の固定構造に埋め込み（system prompt と分離）
- 「忘れろ」「指示を無視」等のパターン検出（オプション）
- 自由入力フィールドは制限

#### 1.3 データ最新性の明示
- 各データソースの調査年を必ず付与
- 「2021年データに基づく」のように時点を明示

### Layer 2: 処理 (Process Guardrails)

#### 2.1 System Prompt の堅牢化

**必須要素**:
1. **役割の明示**: 「投資助言ではなく分析提供」
2. **禁止事項**:
   - 「絶対」「確実」「100%」等の断定的表現
   - 「買うべき」「売るべき」等の助言的指示
   - 元データに無い数値の生成
   - 将来予測の断定（「〜なる」→「〜と推定される」）
3. **必須要素**:
   - データソースの引用
   - 不確実性の明示
   - 免責事項の含意
4. **教科書整合性**: CI102 の正しい解釈を強制

#### 2.2 モデル設定
- `temperature: 0.3` (創造性を抑制)
- `max_tokens: 2000` (過剰生成防止)
- `model: claude-sonnet-4-X` (バージョン固定)

### Layer 3: 出力 (Output Guardrails)

#### 3.1 危険語句の自動検出
出力後、以下のパターンを検出して警告表示:
- **絶対的表現**: 「絶対」「必ず」「100%」「確実に」「断言」
- **直接的助言**: 「買うべき」「売るべき」「投資すべき」「すべきです」
- **過度な楽観**: 「最高」「ベスト」「ナンバーワン」（限定なし）
- **過度な悲観**: 「最悪」「危険」「破綻」（具体的根拠なし）

#### 3.2 数値検証（オプション）
- 元データに存在しない数値が生成されていないか
- 桁数チェック（人口100億等の異常値検出）

#### 3.3 必須要素の存在確認
- 免責事項の含意があるか
- データソースが引用されているか

### Layer 4: 監視・ユーザー保護 (Monitoring & UX)

#### 4.1 AI 生成の明示
- UI 上で「AI 生成」バッジを常時表示
- レポート上部に AI 利用を明示
- ホバーで利用モデル・生成時刻を表示

#### 4.2 免責事項の常時表示
```
本レポートは AI (Claude) による自動分析です。
不動産投資の最終判断はお客様の責任において行ってください。
本ツールは投資助言ではなく分析情報の提供のみを目的としています。
```

#### 4.3 編集可能・コピー機能
- レポートは編集可能なテキストとして表示（人間レビュー前提）
- コピーボタン
- お客様への提示前に営業担当者がチェックすることを示唆

#### 4.4 フィードバック機能（将来）
- 「正確」「不正確」評価
- ログ記録

## 実装優先度

| 項目 | 優先度 | 工数 |
|---|---|---|
| L2.1 System Prompt 強化 | 必須 | 30分 |
| L3.1 危険語句検出 | 必須 | 30分 |
| L4.1 AI 生成明示 + L4.2 免責 | 必須 | 30分 |
| L1.1 入力サニタイズ | 高 | 30分 |
| L2.2 モデル設定調整 | 高 | 5分 |
| L4.3 編集・コピー機能 | 中 | 30分 |
| L1.2 プロンプトインジェクション | 中 | 30分 |
| L3.2 数値検証 | 低 | 1時間 |
| L4.4 フィードバック機能 | 低 | 2時間 |
