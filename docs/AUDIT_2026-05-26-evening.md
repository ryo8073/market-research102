# 体系的精査 — 計算済みデータと UI 表示の照合

## 🔴 未活用フィールド（計算しているが表示されていない）

### 1. `pop_change_10y_pct` (10年人口変化率)
- **生成元**: `precompute_json.py:561-563`
- **参照数**: type定義のみ (0件の実利用)
- **CI102 的価値**: 短期(10年)の人口動態は中期(20年)よりも需要予測の確度が高い。長期と並べると人口減少の加速度合いが分かる
- **対応**: `pop_change_pct` (20年) と並べて表示

### 2. `max_flood_depth` (市区町村の最大浸水深ランク)
- **生成元**: `precompute_json.py:370`
- **参照数**: 0件
- **CI102 的価値**: 浸水リスクの絶対値は地価・住宅需要に直結
- **対応**: MunicipalityDetail と地図のホバーで表示

### 3. `nearest_station_name` (最寄り駅名)
- **生成元**: OSRM CSV
- **参照数**: 1件のみ (型定義に近い)
- **CI102 的価値**: 「最寄り駅まで車5分、駅名: XXX駅」とお客様に説明可能
- **対応**: MunicipalityDetail のアクセス性に明示

### 4. `pop_projection` (2020〜2070年の人口予測)
- **生成元**: `precompute_json.py:551-556` (7時点)
- **参照数**: 3件 (限定的活用)
- **CI102 的価値**: 物件耐用年数 50年内の人口推移を時系列表示すれば**長期投資判断の決め手**
- **対応**: 線グラフで2020-2070年の人口推移を表示

### 5. `daytime_population` (昼間人口推計)
- **生成元**: 計算済み
- **参照数**: 2件
- **CI102 的価値**: 商業・オフィスの需要は昼間人口に比例。夜間人口との差で『通勤流入規模』を可視化
- **対応**: スコアカードのKPI に常時表示済（OK）が、解説で活用されていない

## 🟡 詳細タブの分類粒度未対応

### 6. LQ タブ (①) — 大分類のみ
- `pref.lq_table` (大分類17業種) から計算
- スコアカードで「中分類で見る」と切替しても、LQ詳細タブは大分類のまま
- **問題**: お客様が中分類の95業種別 LQ ランキングを見たい時に、現状この機能がない

### 7. EBM タブ (②) — 大分類のみ
- 同上の問題。需要予測カスケード（基盤雇用→総雇用→人口→住宅）も大分類版で実行される
- **問題**: 中分類でEBMが大きく変わる地域では、需要予測の数値も同様に変わるべき

### 8. シフトシェアタブ (③) — 大分類のみ
- `pref.shift_share_table` (大分類17業種、2016→2021)
- 中分類版のシフトシェアは事前計算していない
- **問題**: 細分業種の競争力分析（情報サービス業のRS、機械器具卸売業のRS等）が見えない

## 🟢 /compare ページの未対応

### 9. /compare は大分類のみで比較
- `pref.ebm`, `pref.basic_ratio`, `pref.suitability_score` のみ使用
- 中分類版 / 農林業補完版で比較する機能がない
- **問題**: 地方農業県（鹿児島・宮崎等）を比較する時、大分類だと過小評価される

## ⚪ 投資判断接続の改善余地

### 10. セグメント分類と物件タイプの紐付けが弱い
- 市区町村セグメント（商業観光型・工業基盤型等）は表示されている
- が、「商業観光型 → 店舗・ホテル投資向き」のような**物件タイプレコメンド**が出ていない
- **問題**: CI102 の真髄は『データから物件タイプを判断する』だが、現状はデータ列挙で止まっている

### 11. NLNI×経済データのクロス分析が不足
- 地価 vs 基盤雇用比率 のクロスは /compare 散布図にある
- が、「商業地域 + 高地価 + 商業セクター漏損」のような**3軸クロス**は未実装
- **問題**: 「この物件は商業地域で地価高め、商業漏損もあるため出店適地」のような複合判断ができない

### 12. 立地適正化計画の活用が部分的
- `has_location_plan` フラグはあるが「居住誘導 vs 都市機能誘導」の区別なし
- **問題**: 投資物件が「居住誘導区域」内なら住宅投資の追い風、「都市機能誘導区域」なら商業投資の追い風、と分かれる
