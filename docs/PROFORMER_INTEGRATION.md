# Proformer → CI102 連携仕様

## 概要

Proformerの物件分析画面から、物件住所の市区町村コードをURLパラメータで渡すと、
CI102が自動的に通勤経済圏（都市雇用圏）を検出し、経済基盤分析を表示します。

**Proformer側の実装イメージ:**
1. ユーザーが物件住所を入力して分析
2. 住所から市区町村コードを取得（Proformer側で処理）
3. 「経済基盤分析を見る」リンクを生成 → CI102に遷移

## URL仕様

### 推奨: `?center=` で市区町村コード（5桁）を渡す

```
https://ci102-market-analysis.vercel.app/?center={市区町村コード5桁}
```

**これだけでOK。** CI102側が自動的に通勤経済圏を検出します。

**例:**
| Proformerの物件住所 | 生成するURL | CI102の動作 |
|---|---|---|
| 東京都千代田区丸の内1-9-1 | `?center=13101` | 東京MEA（147市区町村）で経済圏分析 |
| 東京都練馬区豊玉北5-1 | `?center=13120` | 東京MEA（147市区町村）で経済圏分析 |
| 大阪府大阪市中央区本町1-1 | `?center=27128` | 大阪MEA で経済圏分析 |
| 香川県高松市番町1-8-15 | `?center=37201` | 高松McEA で経済圏分析 |
| 北海道札幌市中央区北1条西2 | `?center=01101` | 札幌MEA で経済圏分析 |
| 秋田県五城目町（農村部） | `?center=05361` | 秋田MEA で経済圏分析 |

**政令指定都市の「区」コードでも「市」コードでもどちらでもOK:**
- `?center=01101`（札幌市中央区）→ 札幌MEA
- `?center=01100`（札幌市）→ 札幌MEA（同じ結果）

### 市区町村コードが取れない場合: `?pref=` で都道府県コード

```
https://ci102-market-analysis.vercel.app/?pref={都道府県コード2桁}
```

**例:**
- `?pref=13` → 東京都の投資判断ハブを表示（経済圏はユーザーが手動選択）
- `?pref=37` → 香川県

**注意:** `?pref=` の場合は経済圏の自動検出はされません。ユーザーが手動で選択します。
市区町村コードが取得できる場合は必ず `?center=` を使ってください。

### 上級: 経済圏を明示指定

```
https://ci102-market-analysis.vercel.app/?zone={コード1},{コード2},...
```

**例:**
- `?zone=13101,13102,13103,13104,13113` → 都心5区で経済圏分析

これはProformer側で独自の経済圏ロジックを実装した場合に使用。
通常は `?center=` で十分です。

### 市区町村コード（5桁）

総数: **1,918市区町村**

コード体系: `{都道府県2桁}{市区町村3桁}`
- 例: `13101` = 東京都(13) + 千代田区(101)
- 例: `37201` = 香川県(37) + 高松市(201)

**政令指定都市の注意:**
- 政令市の「市」コードは `XX100`（例: 札幌市=01100, 横浜市=14100）
- 政令市の「区」コードは `XX1XX`（例: 札幌市中央区=01101, 横浜市西区=14103）
- **どちらを渡しても同じ経済圏に自動解決されます**

**全市区町村コードのCSV:**
- `ci102-nextjs/public/data/code_list.csv` に全件リストあり
- または `ci102-nextjs/public/data/muni_industry_matrix_mid.json` のキー一覧

## 通勤経済圏（UEA）について

経済圏の自動検出には東京大学CSIS「都市雇用圏」（2020年国勢調査ベース）を使用。
- 通勤者の10%以上が中心市に通勤する市区町村を経済圏として定義
- 全国211ゾーン（MEA 103 + McEA 108）
- 1,263市区町村がいずれかのゾーンに所属
- 残り655市区町村（農村部等）はゾーン未所属→単一地域分析にフォールバック

## Proformer側の実装メモ

### 住所→市区町村コードの変換

Proformer側で物件住所から市区町村コードを取得する方法:
- 国土地理院 Geocoding API → 緯度経度 → 逆ジオコーディング → 市区町村コード
- または住所の「都道府県+市区町村」部分から直接コード表を参照

### リンクの生成例

```javascript
// Proformerの物件詳細画面で
const cityCode = "13120";  // 物件住所から取得した市区町村コード
const ci102Url = `https://ci102-market-analysis.vercel.app/?center=${cityCode}`;
// → リンクボタン「経済基盤分析を見る」
```

### 将来拡張（URL仕様の変更は不要）

- `?center=` でcityCodeを渡すだけで、CI102側のロジック改善（閾値変更・Louvain・OD行列等）が自動反映
- Proformer側のコード変更は不要
- 将来Proformer側で独自の推奨経済圏ロジックを実装した場合は `?zone=` で明示指定も可能
