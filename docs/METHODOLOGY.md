# 不動産市場分析ダッシュボード — 分析方法論

## 知的財産としての方法論

本ツールは以下の3つの独自技術を統合した不動産投資エリア分析エンジンです。

### 1. CCIM CI102 経済基盤分析の日本市場適用

米国CCIM（Certified Commercial Investment Member）の CI102 "Market Analysis for Commercial Investment Real Estate" の分析フレームワークを、日本の政府統計データ（e-Stat）に適用。

**独自性**: CI102は米国MSA（Metropolitan Statistical Area）向けに設計されているが、本ツールは日本の市区町村コード体系・経済センサス・国勢調査に完全適合させた。特に中分類95業種でのLQ/EBM計算は、大分類17業種では過大評価されるEBMの問題（Mulligan凸性質）を解決。

### 2. 通勤経済圏の自動検出（3層構造）

| 層 | 手法 | データソース |
|---|------|------------|
| Phase 1 | CSIS都市雇用圏（UEA） | 金本・徳岡方式、211ゾーン |
| Phase 2 | 通勤OD行列 + 閾値カスタム | e-Stat 従業地・通学地集計、307,832ペア |
| Phase 3 | Louvainグラフクラスタリング | 通勤ネットワークのモジュラリティ最大化 |

**独自性**: CI102の分析単位を「行政区」から「通勤経済圏」に拡張。これにより、大都市のEBM過大評価問題を構造的に解決。全国1,919市区町村の通勤ネットワークをLouvainアルゴリズムで5段階の解像度でクラスタリング。

### 3. 5物件タイプ別スコアリング

住居系・商業系・オフィス・物流工業・医療介護の5タイプに対し、各タイプ固有の重み付けでスコアを算出。

**独自性**: 同一エリアでも「住居は推奨だがオフィスは様子見」のような粒度の判定が可能。重み付けはCI102のSite Selection手法に基づく。

### 4. データパイプライン

| データ | ソース | 更新頻度 | 粒度 |
|--------|--------|---------|------|
| 産業・雇用 | e-Stat 経済センサス | 5年 | 中分類95業種 × 1,918市区町村 |
| 人口・世帯 | 国勢調査 | 5年 | 2000-2025実測 + 2050推計 |
| 不動産取引 | MLIT | 四半期 | 全種別・全都道府県 |
| 通勤流動 | 国勢調査OD | 5年 | 全市区町村間ペア |
| 空間データ | 国土数値情報 | 年次 | 洪水・地価・鉄道・用途地域 |
| 借家比率 | 国勢調査確報 | 5年 | 持ち家/借家/公営/民間/給与 |
